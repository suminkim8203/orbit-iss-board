# T05 작업 규약

요약: 공개 보존 ISS 기록 CSV 다운로드 한 기능을 두 AI 세션이 순서대로 완성한다. 비교 대상은 서비스 이름 대신 도구 X(A), 도구 Y(B)로 표시한다. 역할이 다르므로 순수 모델 성능 순위로 해석하지 않는다.

## 작업 전에 고정한 조건

- 시간 상한: AI별 45분(2700초). A/B 시작 이벤트부터 인계/완료 이벤트까지 벽시계 경과시간. 검사와 인수인계 작성 시간을 포함한다.
- 요청 상한: AI별 사용자 작업 메시지 8회. 최초 요청, 추가 수정 요청, 인수인계 요청을 포함한다. 한 메시지 안의 여러 지시는 1회이며 내부 도구 호출은 이 선택 지표에 합산하지 않는다.
- 모델/서비스: A는 사용자가 이 대화의 AI로 지정. B는 사용자가 지정한 학원 자체 AI의 별도 서비스. B의 정확한 표시명과 무료 사용 여부는 시작 전에 사용자가 확인하여 비공개 기록에 보관한다. 비교표에는 이름을 노출하지 않는다.
- 고정 기능 검사: `fixed-tests-v1.md`의 T05-F01~F10 정확히 10개. 자동 구현은 `app/tests/t05/csv.spec.mjs`이다.
- 삭제/완화/기대값 변경: 0건. 시험 자료/검사 소스의 SHA-256을 A 시작 전에 기록한다.
- 구현 시작 전 준비: 저장소 복제, 기존 오류 점검, 실행 가능한 검사와 문서 준비. 준비 시간과 준비 검사는 A/B 구현 측정에 포함하지 않으며 별도 phase로 남긴다. A와 B에게 동일하게 이 측정 경계를 적용한다.
- A 기본 구현 → 고정 검사 → 일곱 항목 인계 → 새 폴더 재현 → B 시작 → B 완료 순서이다. A의 모든 검사 통과를 미리 가정하지 않는다. 의도적 오류 삽입은 하지 않는다.
- B에게는 Git 저장소와 A가 고정한 HANDOFF.md만 제공한다. 대화 전문은 주지 않는다. 공통 최초 요청도 저장소에 포함한다.
- 오류 회차는 같은 고정 검사 10개 실행 중 하나 이상 FAIL이 나온 회차 수다. 기반 도구의 설치 실패는 기능 검사 실행으로 꾸미지 않고 별도로 기록한다.
- 버전 쌍: A 시작/종료, B 시작/종료 각각 전체 Git SHA. 재작업량을 수기로 기입하지 않는다.

## 사전 중단 기록

2026-09-09 저장소 `a5c034dea460468029e4618f45a47ac5a75bda2b`를 복제했다. 사용자는 사용량 소진으로 중단되었다고 알렸다. 이때 제품 코드는 변경되지 않았고 공식 A 구현 시작 이벤트도 없었다. 2026-09-10 T03/T04 비교 후 사용자가 기존 T04 방안 재개를 지시했다. 비교/자료 전달 대화는 구현 요청 집계에 포함하지 않는다. 이번 재개 지시를 공식 A 구현 작업의 최초 사용자 요청 1회로 기록한다.

## 검사 실행

Node.js 24를 사용한다. 저장소 루트에서:

```sh
npm ci --prefix app
cd app
npx playwright install chromium
cd ..
npm run test:t05 --prefix app
```

Linux에서 브라우저 시스템 라이브러리가 없으면 `npx playwright install --with-deps chromium`이 필요하다. 검사는 테스트 전용 Vite 서버를 127.0.0.1:5185에 띄우고 종료한다. 같은 포트의 다른 서버를 재사용하지 않는다. 실서비스나 API를 호출하지 않고 테스트 전용 설정에서만 자료를 주입한다. 결과는 `evidence/t05/`에 시각별 JSON으로 쌓인다. `T05_PHASE` 환경값으로 `A`, `B`, `preparation`, `reproduction`을 구분한다. `T05_RESULT_DIR`로 결과 저장 폴더를 변경할 수 있다.

`app/tests/t05/vite.config.mjs`는 공개 기록과 합성 첫날값을 시험 서버에서만 치환한다. F08은 실제 화면에 430 및 999 pt가 보이는 것을 확인한 뒤 내보낸 CSV를 검증한다. 제품용 `vite.config.ts` 및 실제 관측 JSON에는 시험 데이터를 넣지 않는다.

기존 과제 4 검사/빌드/린트는 별도이다:

```sh
npm test --prefix app
npm run build --prefix app
npm run lint --prefix app
node scripts/verify-assets.mjs
node scripts/scan-secrets.mjs
```

배포는 기존 GitHub Pages 방식을 유지한다. A 중간 상태는 B 인계를 위한 소스이며 기존 공개 T04 사이트에 자동 배포하지 않는다.
